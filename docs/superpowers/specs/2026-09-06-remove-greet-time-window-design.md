# 移除主动招呼时段限制

## 目标

删除 `scripts/greet_only.py` 的 Asia/Shanghai 09:00–21:00 执行限制，使确定性招呼执行器可在任意时间运行。

## 最小改动

- 保留 `_now()` 的时区归一化，用于确定当天计数日期和事件时间。
- 删除 `_assert_send_window()`，改为直接调用 `_now()`。
- 删除 README 和 Windows 使用说明中的现行时段限制描述。
- 不修改每日 150 上限、1500 人扫描上限、单线程发送、资格筛选、黑名单、跨账号去重或平台风险停止规则。

## 验证

运行 `scripts/test_greet_only.py`，并在 21:00 后执行真实 runner；runner 能通过启动阶段即证明时段限制已移除，后续仍由原有风险规则约束。
