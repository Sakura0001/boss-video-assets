# 求职期望黑名单九项扩展 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将主动打招呼的求职期望硬编码黑名单扩展为“算法、通信、硬件、前端、unity、电气、数据、产品、分析”，并确保命中者不会触发打招呼、状态写入或三条消息发送。

**Architecture:** 保留 `EligibilityPolicy.evaluate()` 现有的去空白、小写化和子串匹配，只扩展顶层固定元组。已安装 `boss-zhaopin` skill 仍是业务唯一来源，更新源文档与契约测试后用同步脚本覆盖仓库镜像。

**Tech Stack:** Python 3 标准库、`unittest`、Markdown/YAML 业务规则、Git。

## Global Constraints

- 只检查 `candidate.expect`，不检查教育专业、优势或其他字段。
- `数据`、`产品`、`分析` 均采用宽泛子串匹配。
- 命中时返回 `expectation_blocked`，不得 greet、写状态、写去重或发送三条固定消息。
- 不运行真实 Boss 动作进行测试；只有全部验证通过后，才响应用户本次显式实时运行请求。
- 不提交候选人资料、聊天内容、本地状态、Cookie、Token 或凭据。
